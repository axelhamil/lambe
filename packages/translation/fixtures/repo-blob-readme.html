Widget

Widget is a small library that renders interactive charts from plain data files. It keeps the rendering fast on large datasets by drawing only the points that change between two frames.

The library has no runtime dependencies, works in every modern browser and ships typed definitions for editors that understand them.

Installation

Install the package from the registry with your package manager of choice:

npm install @acme/widget

Then import the chart you need and mount it on an element that already has a size.

Features

  • Line, bar and area charts that share one data model.
  • Incremental redraws that touch only the changed points.
  • Keyboard navigation between data points, with readable labels for screen readers.
  • A theme object that follows the colors of the host page.

Usage

Create a chart, give it a data source, and call render once. Later updates go through the same data source, and the chart redraws itself when the data changes.

import { lineChart } from "@acme/widget";

// Mount the chart on an element that has a size.
const chart = lineChart(document.querySelector("#chart"));
chart.render(source);

Retry policy

When a data source fails, the chart keeps the last good frame on screen and retries three times with a growing delay. After the third failure it shows a short message and stops until the source reports new data.

Contributing

Read the contributing guide before you open a pull request. Every change needs a test that fails without it, and the whole suite must pass on your machine first.
