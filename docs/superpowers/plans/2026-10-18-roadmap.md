## Plan 1: engine, page translation, bubble

File: `2026-10-18-plan-1-page-translation.md`. Creates the monorepo and its tooling, the framework free translation engine (segmentation model, placeholder protection, page brief, prompt adapters for TranslateGemma and instruction models, batching sized to the model context, response validation, priority queue, cache policy), the Ollama native adapter, the DOM adapter that translates in place and restores exactly, the WXT extension (background worker, content script, toolbar action and shortcut) and the Shadow DOM bubble (drag, snap, tail flip, click toggle, double click re-translate, error state). Ends with a real Chrome proof on a saved GitHub doc page. Configuration is a typed object with defaults in `chrome.storage.local`; there is no UI for it yet.

## Plan 2: settings, providers, prompt editor, per site, shortcut

Adds the React and shadcn options page (React 19, Tailwind 4 for layout only, tokens in the global CSS), the OpenAI compatible provider adapter, several providers with one active, connection test showing the exact `OLLAMA_ORIGINS` fix on 403, the editable prompt with reset and visible version, default target language, per site auto translate, hidden bubble and glossary, cache size and clear, and the right click bubble menu (page target language, auto translate this site, hide on this site, open settings). Replaces the Plan 1 config object by a settings store behind the same port.

## Plan 3: YouTube with existing captions

Main world script reading the player's own json3 caption responses, the control bar button next to CC, sentence re-segmentation of auto generated captions, windowed translation ahead of the playhead, Lambë's own caption overlay, cache reuse through the Plan 1 engine. Plan: `2026-10-23-plan-3-youtube-captions.md`. Plan 4 plugs into it: companion segments become a `CaptionTrack` with `generated: false` sentences fed to the same `CaptionTranslationService`.

## Plan 4: companion for videos without captions

Python uv project with faster-whisper large-v3, multilingual CTC alignment adapted from Afterlive, yt-dlp audio fetch, localhost server with shared token, idle model unload, `systemd --user` unit, and the extension side client that feeds companion segments into the Plan 3 pipeline.

## Plan 5: eval harness

Script running a fixed segment set (including the Plan 1 fixtures) through several models and prompt versions, writing a side by side report to choose the default model on evidence (`translategemma:12b` against `gemma4:12b-it-qat` and Mistral Small). Reuses the Plan 1 prompt adapters and parser; independent of Plans 2 to 4, so it can start once Plan 1 is merged.
