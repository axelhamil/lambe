# Docs

Every page of `docs/`, linked from here.

Lambë is a free, open source Chrome extension that translates web pages and YouTube captions in place, with the model you choose: Ollama on your computer by default, or any OpenAI-compatible server.

New here? Read [the README](../README.md) first ([en français](../README.fr.md)), then the [local AI guide](local-ai.md) to get a model running. Come back to the other pages when you want one thing.
