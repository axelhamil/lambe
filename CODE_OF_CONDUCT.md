# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). By participating, you agree to abide by its terms. Issues and PRs are welcome in English or French.

## Reporting

Report unacceptable behavior in a [GitHub issue](https://github.com/axelhamil/lambe/issues), or privately through [a security advisory](https://github.com/axelhamil/lambe/security/advisories/new) when it should not be public. Reports are handled with discretion.
